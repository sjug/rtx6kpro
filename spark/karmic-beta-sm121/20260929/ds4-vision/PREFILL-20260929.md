## Launch configuration

The goal is the best serving configuration, not R38 reproduction. The image's own
`serve-ds4-flash.sh` (unchanged since the Sept 20 image, digest `3542a3f6...`) already
carries upstream beta's ds4-vision defaults: AOT compile, FlashInfer sampler, CUDA graph
memory estimation, multi-stream GEMM threshold 1024, async scheduling, prefix-cache
retention 4096, W4A8 B12X MoE, FP8 KV, block 256. Relative to the Sept 20 wrapper, three
historical overrides were dropped so upstream defaults apply: FlashInfer autotune (now on),
`reasoning_effort` (now `high`), multimodal processor cache (now default). GB10-specific
choices kept in `run-node.sh`: utilization 0.85 (the recipe's 0.975 is an RTX PRO
dedicated-VRAM value), `NCCL_PROTO=LL,Simple` on the pair rails, explicit 524,288 context,
TP2/DCP1, DSpark K3 probabilistic, 4 sequences, 4,096 batched tokens, capture sizes to 16.
